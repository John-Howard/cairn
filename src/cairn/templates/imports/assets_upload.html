Import information assets

Bulk load an asset inventory or CMDB extract: upload a mapped CSV and each row becomes an approved information asset. You'll see a preview with any row errors before anything is created. To bulk-load processing activities rather than assets, use import questionnaire.

Download the CSV template — it has every column in the right order, with example rows showing the expected values.

Before uploading, check that:

  • the template's example rows are deleted (their labels start with “EXAMPLE:”)
  • every row has a label and an asset_type — all other columns are optional
  • dates are in YYYY-MM-DD or DD/MM/YYYY format
  • multiple security_measures are separated with semicolons

The full list of columns and accepted values is in the CSV contract below.
